Lorenz

A daily cipher puzzle on the Lorenz SZ40/42 cipher machine that Bletchley Park called Tunny, a cipher attachment used with a teleprinter.

Look up today's QEP number in the book, set the twelve wheels, and run the intercepted tape. Get it right and the teleprinter prints the message. Get one wheel wrong and you get garbage.

Mode

Normal: the QEP number is given and the teleprinter prints the message.

Twelve wheels, 501 cams, a new intercept every day at 00:00 UTC.

I'm Arthur. I made Skywave, and this is its sister. Tunny traffic went out by radio, which is how I got hooked on it... The machine logic follows the wartime reports as closely as I could manage. If you know better, email me.

Encipher

Type a message and run it through the machine with the wheel settings below and today's cam patterns. Paste the tape back in with the same settings and you get your message back, because adding the same key twice cancels out.

Letters, figures, spaces and . , ? / ( ) : = + % ' work. Anything else is left out.

Just the five chi wheels, with no psi or motor wheels, so the key is the chi on its own. This matches the printable model.
