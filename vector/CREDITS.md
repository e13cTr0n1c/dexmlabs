# VECTOR credits

Original game implementation, interface, procedural radar artwork and fictional airspace for DEXM Labs. No third-party game engine, graphics library, aircraft dataset, map service, audio recording or font file is bundled.

The site identity, shared theme, points ledger and existing assets come from the website source supplied for this update. Original content follows the repository's existing DEXM Labs copyright notice.

Radar geometry, aircraft performance and separation rules are deliberately simplified. Callsigns and the sector are fictional. No aviation organisation endorsement is implied.
