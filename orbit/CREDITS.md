# ORBIT credits and provenance

## Earth texture

`assets/earth-day.jpg` is a copy of `skywave/assets/textures/earth_day_2k.jpg` from the website source supplied for this update. It is not newly downloaded imagery.

The supplied provenance identifies the image as **NASA Blue Marble Next Generation**, distributed as `bmng.jpg` by the Basemap data package, then resized and recompressed. The existing Skywave credits attribute the source to NASA Earth Observatory / Reto Stockli and collaborators. The game remaps the supplied texture into an illustrative illuminated globe in Canvas 2D.

The original provenance and fuller source attribution remain in `../skywave/CREDITS.md` and `../skywave/assets/textures/provenance.json`.

- NASA collection: https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/
- NASA media guidance: https://www.nasa.gov/nasa-brand-center/images-and-media/

No NASA insignia is used. NASA does not endorse this game. Screenshots, homepage thumbnails and social previews include the same credited Earth image.

## Simulation reference and implementation

The code is an original, simplified planar two-body game implementation for this website; it is not NASA flight software. The general orbital-mechanics reference consulted was NASA's Basics of Space Flight, Chapter 3:

https://science.nasa.gov/learn/basics-of-space-flight/chapter3-1/

No third-party game engine or graphics library is bundled. The site identity, existing theme and shared points system come from the supplied DEXM Labs repository. Original content follows the repository's existing copyright notice.
